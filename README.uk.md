# Silpo Voice Shopping Agent

Голосовий агент для замовлення продуктів у Сільпо: кажеш, що потрібно — агент розбирає фразу на конкретні товари, шукає їх у реальному каталозі Сільпо (через MCP), збирає кошик за вказаною адресою і передає тебе на оформлення замовлення. Зроблено для хакатону Silpo AI Factory.

- **Живий деплой:** https://silpo-voice-shopping-agent.vercel.app
- **Демо-відео з хакатону:** https://www.youtube.com/watch?v=W4zIgaQPTrM

![Приклад прогону](public/example-run.png)

## Як користуватись

1. Береш мікрофон (або вводиш текст) і кажеш щось на кшталт «два літри молока, хліб і горішки по акції».
2. Агент розбирає фразу на конкретні пошукові запити з кількістю та критерієм вибору («по акції» тощо), шукає кожен товар у Сільпо і показує знайдене.
3. Перед тим, як щось потрапить у кошик, з'являється запит на підтвердження — можна прибрати окремі позиції або скасувати все.
4. Після підтвердження товари додаються в кошик за вказаною адресою, результат озвучується і показується як список із сумою та кнопкою «Оформити замовлення».
